# 含噪 PLECS 数据：接口初始化与窗口重测

本目录记录本次适配器开发中的完整对照结果，含表现不佳的设置。读取用户已有的 Case16A/B 含噪归档，没有执行新的 PLECS 仿真。

## 数据与评价边界

- 使用每组归档中的 0–0.8 ms 训练段：干净数据，以及 1%/3% 高斯测量噪声、种子 12/13/14。噪声按各通道训练信号 RMS 定义，在原实验的 20 ns 插值网格上添加。
- 输入只取时间、含噪电流/电压和实际 PWM。归档的驱动第一列为 0/28 V，先除以 Vin 转成 0/1；PWM 零阶保持。归档的干净参考、反馈电流和元件真值不传给拟合器。
- 本次数值对照为 LC 辨识，固定 R=6 Ω、Vin=28 V、fs=100 kHz。Case16A 的 L/C 真值为 60 μH/500 μF，Case16B 为 40 μH/750 μF；只在拟合结束后计算误差。各工况独立重新辨识。
- 这里没有自主闭环或独立留出仿真，不能把本表称为闭环泛化验证。产品 API 的连续后段留出另有数据泄漏回归测试，但其输入仍为实测 PWM。
- 所有指定种子保留。参数/状态按最小含噪训练损失选同一轮次，不按真值筛选。JSON 中记录数据 SHA-256、源码 SHA-256、所有窗口状态、损失轨迹和预算情况。

## 初始化结果

下面均为三个 **3% 噪声种子中 C 的最大绝对相对误差**，仅评价初始化，还没有 PANN 微调。

| 数据 | 原端点差值积分初始化 | 新端点零权重积分初始化 |
|---|---:|---:|
| Case16A | 82.060% | 0.291% |
| Case16B | 82.504% | 0.290% |

新方法在 2/5/10 周期窗口上使用 φ(u)=u²(1−u)²，通过分部积分消除显式端点差值；不是直接对波形求数值导数，也不需要真实参数作为初值。它仍可能受模型误差、激励不足和相关噪声影响。这两组高密度高斯噪声数据上的小误差不能推广到任意上传 CSV。

## PANN 的短窗口限制

Case16A、3% 噪声、每项保留三个种子：

| 设置 | 状态预热轮数 | 参数更新轮数 | C 最大绝对误差 |
|---|---:|---:|---:|
| 固定含噪状态，1 周期 | 0 | 100 | 41.601% |
| 直接联合状态/参数，1 周期 | 0 | 100 | 32.569% |
| 先估计状态再联合，1 周期 | 50 | 100 | 32.304% |
| 先估计状态再联合，1 周期 | 50 | 300 | 32.554% |
| 先估计状态再联合，3 周期 | 50 | 100 | 6.031% |

不能据此说“联合状态估计一定更准确”：部分种子会变差；新参数初值很接近真值，PANN 仍可能将其拉偏。单独预热或增加轮数没有解决这组短窗口的 C 偏差。3 周期提供更长的窗口内动态，但改变了窗口数量（40→26）和采样位置，这不是只改变时长、其余逐点完全匹配的消融实验。最大误差是三种子统计，不是可靠性上界。

这批实验当时默认采用：训练段噪声估计驱动的自动窗口、状态预热 50 轮、联合更新 100 轮。当前应用默认联合训练已改为 200 轮；以下历史实验仍按原始轮数记录。自动规则在任一通道估计噪声 ≥0.5% RMS 时优先 3 周期，否则 1 周期；短记录缩短窗口以保留至少 4 个窗口。这是基于本次开发观察设置的启发式规则，阈值没有做统计标定；保留手动窗口与固定测量状态对照。这批历史实验使用过 120 秒训练预算，实际完成轮数以归档记录为准。2026-10-23 起应用训练取消时间上限，原始证据文件不改写。

Case16A 的 3 周期测试有一个种子的最佳轮次仍在第 100 轮，不能称为充分收敛。所有默认自动窗口及跨参数补测原始记录见下表。

Case16B 用最终自动配置完成了同样的三个 3% 噪声种子，均选中 3 周期并完成 100 轮；L 最大绝对误差 0.609%，C 最大绝对误差 **6.257%**。两个种子的最佳轮次仍在预算末端。它支持继续使用较长窗口作含噪对照，但尚不足以宣称参数准确、已经充分收敛或适用于任意噪声。

## 复跑最终配置

在项目根目录、已有 PANN Python 环境可用时执行；根据本机位置修改归档路径。真值参数仅供事后评价，不传入辨识器。

```powershell
$env:PANN_PYTHON = 'D:\开学作业\ST4001\PANN-main\.venv\Scripts\python.exe'
.\.venv\Scripts\python.exe tests/benchmark_pann_noise.py 'D:\开学作业\ST4001\仿真\buck_converter_with_parameter_sweep\test\results\case16b\training_inputs.npz' --truth-l-uh 40 --truth-c-uf 750 --epochs 100 --cycles 0 --indices 4 5 6 --states joint --output runtime/case16b-recheck.json
```

去掉 `--indices` 会运行全部七组；去掉 `--states joint` 会进行固定/联合状态的成对测试；`--seed-only` 只检查初始化。前端可选 LCR，但此处固定 R 的噪声对照不能充当 LCR 含噪验证。

- [pwm_pann_smoke.json](pwm_pann_smoke.json)：SG 6 周期、两个 3% 噪声 seed12 样本、200 轮 PANN 衔接检查。保留当次 v1 判据及源码哈希，不追改为 v2。v2 只增加首尾残缺周期筛查，不修改滤波、PWM 或训练计算；这两个完整训练区间也已包含在上述 v2 重建重测中。
